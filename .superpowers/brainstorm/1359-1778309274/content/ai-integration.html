AI 功能集成方案

通义千问 Qwen-VL — 一个模型覆盖识图 + 知识问答

功能 1：拍照识图

拍照识别流程
📸 调用手机相机拍照（Camera API / input capture）
⬇
🗜 前端压缩图片（browser-image-compression，目标 ~300KB）
⬇
🖼 压缩后的图片 → Qwen-VL API (base64)
Prompt: "识别图中的植物，给出中文名称、拉丁学名、科属"
⬇
📋 返回：植物名 + 学名 + 创建/关联植物档案

功能 2：养护知识搜索

文字问答流程
🔤 用户输入植物名或问题（如"月季怎么浇水"）
⬇
💬 Qwen API 调用
System: "你是植物养护专家，回答要具体、可操作"
⬇
📝 结构化返回：光照/浇水/温度/施肥/常见病虫害

API Key 安全方案

纯前端无法真正隐藏 API Key。MVP 阶段采用：

方案

  • 用户在设置页自行填写自己的通义千问 API Key（免费获取）
  • Key 加密存储于 IndexedDB（Web Crypto API 简单混淆）
  • App 本身不内置任何 Key

后续可升级

  • 加一层 Cloudflare Worker / Vercel Function 做代理
  • 用户可选是否使用代理
