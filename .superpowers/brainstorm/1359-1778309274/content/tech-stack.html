技术栈 & 分层设计

Vue 3 + TypeScript + PWA | 纯客户端

四层架构
UI Layer  —  Vue 3 + Vant UI + Vue Router
Service Layer  —  AI API 封装 + 图片压缩
Data Layer  —  IndexedDB (Dexie.js 封装)
Platform Layer  —  PWA Service Worker + Camera API

核心依赖

层技术作用
UIVue 3 + Vant 4 + Vue Router移动端组件、页面路由
构建Vite + vite-plugin-pwa快速构建、PWA 自动配置
存储Dexie.js (IndexedDB)结构化本地存储，存植物数据+照片 Blob
AI通义千问 API（Qwen-VL）视觉识别 + 文本知识问答
图片browser-image-compression上传前压缩，减少 IndexedDB 占用
语言TypeScript类型安全

为什么不选 Pinia

  • MVP 阶段数据规模小
  • Dexie.js 的 reactive API 已够用
  • 需要时再加，成本很低

风险注意

  • Qwen-VL 的植物识别准确率需实测验证
  • API Key 纯前端暴露问题（见后续安全方案）
