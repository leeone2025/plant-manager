植物管理 App — 两种架构方案

Vue + TypeScript + PWA | 纯客户端 | 国内大模型

A

简单单页架构

单一页面 + Tab 切换（植物列表 / AI搜索 / 设置），每个植物一个详情页。直接调用 IndexedDB + AI API

Pros

  • 开发快，结构简单
  • 适合少量植物管理
  • 路由简单，PWA 缓存容易

Cons

  • 扩展性差，功能多了会臃肿
  • 组件复用度低
  • 数据逻辑和 UI 耦合
B

分层组件架构（推荐）

Data Layer（IndexedDB 封装）+ Service Layer（AI 调用）+ Component Layer（Vue 组件）+ 页面路由

Pros

  • 关注点分离，易测试
  • 数据层可替换（后续换后端只需改 data layer）
  • 组件复用，移动端体验一致
  • 适合逐步迭代

Cons

  • 初期文件多一些
  • 需要设计好接口边界
